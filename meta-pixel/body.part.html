Connect the website form to Meta ads — 4 short steps

Связать форму сайта с рекламой Meta — 4 коротких шага

Why: we will test two ways to get trial requests — the Instagram form and the form on totalfitnoah.com. Meta already sees requests from the Instagram form. To see requests from the website, Meta needs a small piece of code on the site. About 20 minutes in total.

Зачем: мы проверим два способа собирать заявки на пробное занятие — форму в Instagram и форму на сайте totalfitnoah.com. Заявки из формы Instagram Meta уже видит. Чтобы она видела заявки с сайта, на сайт нужно добавить небольшой код. Всего около 20 минут.

1

Create the Meta code (a "dataset") and copy its ID

Создать код Meta («набор данных») и скопировать его номер

3 min▾

Done by the person who manages the Facebook page (admin of "Totalfit Noah GYM").

Делает тот, кто управляет страницей в Facebook (администратор «Totalfit Noah GYM»).

Open Events ManagerОткрыть Events Manager
  1. Click + Connect data (green button on the left).
  2. Choose Web → Connect.
  3. Name: TOTALFIT NOAH Website → Create.
  4. If Meta offers partner integrations or a website check — close that window, it is not needed.
  5. Open the new dataset → Settings. Copy the Dataset ID (15–16 digits) and paste it below.
  1. Нажмите + Подключить данные (зелёная кнопка слева).
  2. Выберите Веб → Подключить.
  3. Название: TOTALFIT NOAH Website → Создать.
  4. Если Meta предложит подключить партнёра или проверить сайт — закройте это окно, оно не нужно.
  5. Откройте созданный набор → Настройки. Скопируйте ID набора данных (15–16 цифр) и вставьте ниже.
