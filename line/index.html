LINE: turn new friends into trial bookings

About 30 minutes in the LINE Official Account Manager app. Everything below is free.

Since Nov 21 more than 120 people tapped the ads and went to your LINE. Nobody wrote. The reason: after adding you, people see the default text "we will send news" and there is nothing to tap. We fix this with one button at the bottom of the chat.
STEP 1

Add a "Book a free trial" button (rich menu)

This is a big button under the chat. One tap sends the message "I want to book a free trial" for the person, they don't have to type anything.

Download this image
  1. Home → Rich menu (リッチメニュー) → Create
  2. Title: 無料体験. Display period: from today, end date far away (e.g. 2027).
  3. Template: size Small (小), the one with 2 equal halves. Upload the image above.
  4. Area A (left, green): type Text (テキスト). Paste:
    無料体験を予約したいです
  5. Area B (right, black): type Link (リンク): https://totalfitnoah.com/
  6. Menu bar text (メニューバーのテキスト): Other (その他), paste:
    無料体験の予約はこちら
  7. Default display (メニューのデフォルト表示): Show (表示する). Save.
STEP 2

Instant reply when someone taps the button

So the person gets an answer in a second, even at night. Your staff then confirms the date.

  1. Settings → Response settings (応答設定): Chat ON, Greeting message ON, Auto-response (応答メッセージ) ON.
  2. Home → Auto-response (応答メッセージ) → Create
  3. Keywords: 無料体験を予約したいです, 体験, 予約
  4. Message:
    お問い合わせありがとうございます！TOTALFIT NOAHです。 無料体験のご予約を承ります。次の2つを教えてください。 1. 体験したいクラス（キックボクシング／ピラティス／フィットネス／卓球／キッズ） 2. ご希望の日にちと時間帯 スタッフから確認のご連絡をします。 ※キッズダンスの体験は500円です。
STEP 3

New greeting message

  1. Home → Greeting message (あいさつメッセージ)
  2. Delete the old text. At the start insert the friend's name with the button Friend's display name (友だちの表示名), then paste:
    さん、友だち追加ありがとうございます！TOTALFIT NOAHです。 無料体験は、画面下の「無料体験を予約する」をタップするだけで予約できます。 このトークに直接メッセージしてもOKです。 手ぶらでOK、初めての方も大歓迎です。
STEP 4

Send one message to your 95 friends

Many of them came from the ads and are still waiting. Do this after steps 1 to 3, so they see the button.

  1. Home → Broadcast (メッセージ配信) → Create → Send to all friends
  2. Paste:
    TOTALFIT NOAHです。友だち追加ありがとうございます！ 無料体験、受付中です。 キックボクシング・ピラティス・フィットネス・卓球、どれでも1回無料で体験できます。手ぶらでOKです。 ご予約は画面下の「無料体験を予約する」をタップするだけ。

The free LINE plan includes 200 messages a month, so 95 friends costs nothing.
